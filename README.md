# JVEX — единый ИИ и JVEX Code

Белo-зелёное веб-приложение с чатом, фотографиями, поиском, выбором режимов, историей и переключением провайдеров при ошибках/лимитах. UI пока не требует сборщика: открывается обычный index.html.

## Что реализовано

- Адаптивное меню JVEX: чаты, поиск по названиям, удаление, экспорт истории.
- История и настройки хранятся на **текущем устройстве в браузере**; синхронизации аккаунтов пока нет.
- Можно прикрепить фото и попросить ИИ его распознать; перед отправкой изображение сжимается до 1280 px.
- Голосовой ввод использует браузерный SpeechRecognition, если доступен.
- Бело-зелёная тема, изменение цвета и тёмная тема в настройках.
- Режимы «Чат» и «Code». Code может читать содержимое **публичного** GitHub-репозитория по адресу owner/repo.
- API-роутер: **Groq**, **OpenRouter/free** и **Gemini**; автоматически пробует следующего провайдера, если предыдущий недоступен. Единый системный промпт и история сообщений.
- Поиск через **Tavily**, когда подключён соответствующий API-ключ. При работе через Gemini возможен Google Search Grounding. Источники отображаются ссылками, когда сервис их предоставляет.
- Код доступен в папке worker, секреты API остаются в Cloudflare.

## 1. Запуск веб-сайта

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow Publish JVEX на каждом push проверяет синтаксис JavaScript и публикует интерфейс.

Ожидаемый адрес: https://vivab.github.io/JVEX/ . **Пока workflow не завершился успешно, нельзя считать сайт опубликованным.**

## 2. Запуск Cloudflare Worker

Создайте бесплатный Cloudflare аккаунт. В каталоге worker выполните:

~~~bash
npx wrangler login
npx wrangler secret put JVEX_ACCESS_CODE
npx wrangler secret put GROQ_API_KEY
npx wrangler secret put OPENROUTER_API_KEY
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put TAVILY_API_KEY
npx wrangler deploy
~~~

Обязательны **JVEX_ACCESS_CODE** и **хотя бы один** ключ модели. Ключи остальных провайдеров и поиска — необязательные. Можно выполнять команды из облачной среды разработки GitHub Codespaces, если нет компьютера. В wrangler.toml ALLOWED_ORIGIN настроен для https://vivab.github.io (домен Pages).

Полученный адрес Worker введите в настройках JVEX вместе с JVEX_ACCESS_CODE. Проверка работоспособности Worker: GET /api/health должен вернуть ok:true, но это не проверяет работоспособность ключей моделей.

## 3. Настройка моделей

Параметры окружения Cloudflare Worker (необязательные):

- GROQ_MODEL — по умолчанию openai/gpt-oss-120b
- GROQ_VISION_MODEL — по умолчанию qwen/qwen3.8-27b
- OPENROUTER_MODEL — по умолчанию openrouter/free
- GEMINI_MODEL — по умолчанию gemini-2.5-flash

Доступность моделей и бесплатные квоты могут меняться. Проверьте модели в консоли провайдера перед запуском. При нехватке лимита API следующая модель получает сохранённый контекст из приложения; полного сохранения внутреннего состояния мысли моделей нет.

## Важно: безопасность

- **Не добавляйте API-ключи в GitHub или в index.html.** Используйте Cloudflare Secrets.
- Сейчас закрытая тестовая версия с единым кодом доступа. Для полноценного публичного запуска потребуются аккаунты, защита от злоупотреблений, лимит на каждого пользователя и проверка условий бесплатных API. Иначе чужие запросы исчерпают общую квоту.
- Код доступа и переписки сохраняются в localStorage браузера. Используйте только доверенное устройство; не отправляйте секрет в чужой браузер.
- Фото, сообщения и фрагменты публичного GitHub-кода передаются внешним API. В бесплатных API могут действовать особые правила обработки данных.
- При неудачном поиске JVEX не должен выдавать сведения за проверенные; веб-поиск не гарантируется для каждого сообщения.
- **JVEX Code пока только анализирует и пишет код**, не выполняет команды, не создаёт коммиты, не запускает тесты и не меняет GitHub-проекты. Это следующий этап с GitHub OAuth/App, ветками, предпросмотром diff и изолированным тестовым окружением.
- APK ещё не собран; будущая сборка возможна с Capacitor.
