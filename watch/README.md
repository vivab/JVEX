# JVEX Watch — голосовой помощник для Apple Watch Series 4

Временный голосовой помощник на один день. Запускается через приложение «Команды» (Shortcuts) на часах. Не требует Mac, Xcode или нового приложения в App Store.

Apple Watch Series 4 поддерживает watchOS до 10.6.1. Голос вводится стандартной диктовкой Apple Watch, ответ произносит системное действие «Произнести текст».

## Создание на iPhone

1. Открой «Команды» → +. Назови команду JVEX Watch.
2. Добавь действие «Диктовать текст» (Dictate Text), выбери русский язык. На часах скажи вопрос и нажми «Готово». Если Dictate Text недоступно, используй «Запросить ввод» (Ask for Input) с типом «Текст» и микрофоном на клавиатуре.
3. Добавь действие «URL» и вставь https://jvex-api.vivogaga12.workers.dev/api/watch
4. Добавь «Получить содержимое URL» (Get Contents of URL): метод POST, тело JSON. Добавь строковое поле с ключом q, а значение — магическая переменная «Диктованный текст» из первого действия.
5. Добавь «Произнести текст» (Speak Text). Для текста выбери результат шага 4 — «Содержимое URL». При желании укажи русский голос.
6. В настройках команды (значок ⓘ) включи «Показывать на Apple Watch». На часах открой «Команды» → JVEX Watch. Для быстрого запуска можно добавить усложнение на циферблат.

Пример тела HTTP-запроса: JSON с одним строковым полем q, равным твоему вопросу. Никаких API-ключей в команду вставлять нельзя и не нужно.

## API

POST https://jvex-api.vivogaga12.workers.dev/api/watch

Принимает JSON со строкой q (до 650 символов), возвращает чистый text/plain, чтобы Speak Text мог сразу прочитать ответ. Модель: Groq GPT-OSS 20B с резервной 120B. Максимальная длина произносимого ответа — 520 символов. Стоимость: одна единица публичного лимита Free (60 единиц/сутки). При сбое обеих моделей единица возвращается.

## Ограничения

Это не нативное watchOS-приложение, не подписанный .shortcut и не готовая iCloud-ссылка. Сборка настоящего watchOS-приложения без Mac и Xcode здесь недоступна.
Каждый запуск — один отдельный вопрос без истории. Нужен интернет через часы или связанный iPhone. Совместимость действий Shortcuts с watchOS 10 должна быть проверена на реальных часах.
На некоторых версиях watchOS действие Dictate Text может потребовать завершения на телефоне; используйте Ask for Input и встроенную диктовку как запасной вариант.
